# mmockett.github.io

Max Mockett's projects as small models on a table: Skim, PLASM, the OP–XY instruments and Spirit Aquarium. Click one to look closer.

A static page: `index.html` holds the words and media for each section, and `js/` draws the table with [three.js](https://threejs.org) (r170, from a CDN). There is no build step; serve the folder with any static server.

Credits for the models and textures are on the page, under Credits.
